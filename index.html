Sistema HIDS (Host-based Intrusion Detection System)
Descripción Completa:

Sistema HIDS desarrollado con Spring Boot que simula un entorno de seguridad empresarial. Implementa arquitectura de agente-servidor para monitoreo de eventos de seguridad.

🎯 Características Principales:
  • Agente simulado que genera eventos cada 15s
  • Dashboard en tiempo real con auto-refresh
  • Persistencia en MySQL con Spring Data JPA
  • Completamente dockerizado (Docker Compose)
  • API REST completa (CRUD de eventos)
  • Clasificación por severidad (CRITICAL, HIGH, MEDIUM, LOW)
🛠️ Stack Tecnológico:
Java 17 Spring Boot 3.5 MySQL 8.0 Spring Data JPA Thymeleaf Bootstrap 5 Docker Docker Compose
